* **Python 3.10** o superior.

```bash
pip install numpy
```

Se necesita estar en la carpeta Tarea1InteligenciaArtificial/Codigo

Ejecutar el scrip principal de pruebas

```bash
python benchmark.py
```

```bash
python3 benchmark.py
```
